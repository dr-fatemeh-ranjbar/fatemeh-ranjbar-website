# نسخه نهایی سایت با تنظیمات ظاهر

این نسخه شامل بخش «تنظیمات ظاهر» در پنل مدیریت است.

امکانات:
- تغییر رنگ اصلی، رنگ تأکیدی، پس‌زمینه، کارت‌ها و متن
- انتخاب فونت
- تغییر اندازه تیتر اصلی و گردی کارت‌ها
- جابه‌جایی کارت تصویر
- نمایش/عدم نمایش هر بخش
- تغییر ترتیب بخش‌های سایت
- مدیریت آنلاین محتوا از Supabase
- آپلود عکس و رزومه در bucket `site-media`

## قبل از Deploy
در فایل `config.js` مقدار `anonKey` را با Publishable Key یا anon key پروژه Supabase جایگزین کن. URL پروژه از قبل وارد شده است.

سپس کل پوشه را روی همان پروژه Vercel دوباره Deploy کن.
